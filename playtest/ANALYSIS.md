# 블라인드 페르소나 플레이테스트 1차 분석 (2026-10-13)

코드: V = P(숫자 돌 Akari, 정답 하나), S = N(현행, 숫자 없음·예산 = 최소), C = E(쉬운 대조군, 예산 = 최소 + 2). 페르소나 8명(35~54세 여성, 미국·영국·캐나다·호주·일본), 코드당 레벨 1·3·8·15, 순서 상쇄. 결과 8개·세션 96개 전수 파싱, 12개 보드 해 개수는 브루트포스로 검증.

**신뢰도**: 테스터는 모두 LLM이고 대부분 머릿속으로 푼 뒤 실수를 연출했다. 시간은 명령 지연이고, 되돌리기·힌트·포기는 일부 연출이다. 가중치는 구조적 사실 > 선호 > 행동 수치.

## 순위

| | P (V) | E (C) | N (S) |
| --- | --- | --- | --- |
| 1위 횟수 | **6** | 2 | 0 |
| Borda 전체 | **13** | 7 | 4 |
| Borda 논리층 5명 | **10** | 2 | 3 |
| Borda 휴식층 3명 (Priya, Sophie, Denise) | 3 | **5** | 1 |
| 내일 10분에 고름 (Q6) | 5/8 | 2/8 | **0/8** |

- 테스트는 유효하다: 8명 전원이 E의 예산이 느슨하다고 지적했고 논리층 3명은 E를 꼴찌로 뒀다.
- 현행 N은 일부러 쉽게 만든 대조군 E에게도 졌다.

## 구조적 사실

- **N은 해가 여러 개다**: 레벨 1/3/8/15의 예산 내 해가 99 / 9 / 16 / 468개. 공유·시간 비교·"정답" 개념이 성립하지 않는다. P는 4개 보드 모두 해가 하나.
- **N의 실패는 끝에서야 드러나고 어느 등불이 틀렸는지 단서가 없다** (6/8).
- **힌트가 상황을 악화시킨다** (5/8): 힌트 19건 중 8건은 제시 칸에 놓는 즉시 충돌. P 레벨 8에서 힌트를 쓴 5명 모두 같은 칸(D1)을 받고 모두 충돌. 원인은 틀린 등불 중 첫 번째 하나만 행 우선으로 지목하는 코드(`tools/play.ts`). E에서도 예산이 아니라 "최적 N개" 기준 문구가 나와 꾸중처럼 읽힌다.
- **"숫자 N/N 맞음"인데 어두운 칸이 남는다** (4/8): 숫자 0 돌은 등불 0개에서도 '맞음'으로 세어진다.
- **P 난이도 태그가 단조롭지 않다**: 레벨 3·8이 hard, 15가 mid. V-8이 가장 큰 벽(힌트 5건).

## 사전 등록 기준

| 기준 | 판정 |
| --- | --- |
| 레벨 1~5 첫 시도 < 40% | 미충족 (P 63%, N 81%, E 100%; 수치는 연출) |
| 6×6 리셋+되돌리기 중앙값 > 3 | 미충족 |
| 깊이 소진 | 측정 불가 (10레벨 미만). 초기 신호: N은 8레벨에서 요령 파악 후 반복 |
| 2일차 "열겠다" < 50% | **N 충족 (0/8)**, E 충족 (2/8), P 미충족 (5/8) |
| "찍기·운·다 똑같다" ≥ 30% | **N 충족 (5/8)**, **E 충족 (5~6/8)**, P 미충족 (1/8) |
| 공유 < 20% | 미충족 (5/8 언급), 단 논리층은 P형일 때만, 휴식층은 쉬울 때만 |

## 7일차 복귀 요인

| 유형 | 수 |
| --- | --- |
| 퍼즐 품질 (P형, 정답 하나, 아하) | 6 |

## 결정

1. **P(숫자 돌, 정답 하나)를 기본 규칙으로 한다. N은 기본 모드에서 뺀다.**
2. **트랙을 둘로 나눈다.** 같은 P-8·P-15를 두고 논리층은 "최고의 아하", 휴식층은 힌트·포기였다.
   - 부드러운 기본 트랙·데일리 (전원 공통, 공유·연속 기록·마을에 연결): 5×5~6×6, 확정 수만으로 풀림(경우 나누기 없음), 정답 하나.
   - 추론 트랙 (선택): 경우 나누기가 필요한 판, 별도 공유 줄.
   - 데일리 하나에 요일별로 어려워지는 곡선은 기각: 휴식층이 어려운 요일에 연속 기록을 잃는다.
3. E는 제품이 아니다. 휴식층이 E를 고른 이유는 "여유가 있고 실패하지 않아서"이므로 답은 **쉬운 P**다.
4. 확신도는 중간. 휴식층이 3명뿐이고 모두 LLM이라 실제 사람 테스트로 확인해야 한다.

## 수정 우선순위

**P0**
1. P를 기본으로 전환.
2. 힌트 재작성: 틀린 등불 전부 표시, 충돌하는 칸 추천 금지, 행 우선 편향과 "최적 N개" 문구 제거.
3. 돌·바닥 대비, 숫자 크기 (8/8).
4. 생성기와 CI에 정답 유일성 게이트.

**P1**
5. "숫자 맞음" 카운터 교체: 0 돌을 미리 세지 않고, 더 이상 밝힐 수 없는 칸을 표시.
6. 두 트랙 난이도 설계, 난이도 태그 단조화, 같은 시작 반복 제거.
7. 빈 공간·설명 없는 점·탁한 조명색 (v2 비주얼에서 상당 부분 해결, 재검증 필요).
8. 데일리 + 연속 기록 + 기호형 공유(영어 없이).

**P2**
9. 마을 메타 진행.
10. 완료 연출. 시간은 공유 문구에만 넣고 화면 타이머는 넣지 않는다(삭제 사유로 꼽힘).
11. 아이콘 위주 문구와 현지화.
12. 유료 힌트·과한 광고 금지 원칙 (7명이 삭제 사유로 꼽음).
