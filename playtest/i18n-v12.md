## 1. 언어 감지 — 완료 (09:30)
- `a11y/strings.ts`: `LANGS`에 `it`, `zh-Hans`, `zh-Hant` 추가. 새 `langOf(tag)`: 태그 하나 → 언어(없으면 null). `pickLang`은 이것으로 첫 번째로 맞는 태그를 고른다(기기 언어 순서 그대로).
  - 중국어: 스크립트 서브태그가 먼저(zh-Hant-* → zh-Hant, zh-Hans-* → zh-Hans, 지역과 상관없이). 스크립트가 없으면 지역: TW·HK·MO → zh-Hant, 나머지(CN·SG·MY·맨 "zh") → zh-Hans. `yue`(광둥어)는 Hans가 명시되지 않으면 zh-Hant, `cmn`도 같은 규칙. 밑줄 태그(zh_TW)와 대소문자 무시.
  - it-* → it. es는 모든 지역(es-ES, es-MX, es-419, es-US …)에 하나. pt-* → pt-BR. 그 밖은 en.
  - 감지 순서는 그대로: 네이티브 플러그인 `Locale.preferredLanguages.first` → `navigator.languages` → `navigator.language`. (WKWebView의 navigator.languages는 앱이 지원하는 현지화(CFBundleLocalizations)에 맞춰지므로 3단계에서 Info.plist도 넓힌다.)
- VoiceOver 문장 이음: `listSep`(ja "、", zh "，", 그 밖 ", "), `sentenceSep`(ja·zh "。"). 전에는 ja만 따로 처리했다.
- 광고 휴식 확인 카드(`ads/breakCard.ts`): 자체 언어 목록 대신 `LANGS`와 `pickLang`을 쓴다(zh-Hant-HK 같은 태그가 en으로 떨어지던 문제 방지).
- 테스트(`a11y.test.ts`): 매핑 표 47개(zh-TW/HK/MO, zh-Hant-*, yue, zh-CN/SG/MY, zh-Hans-HK, 맨 zh, it-CH, es-419·es-MX·es-US, 지원하지 않는 언어 → en, 기기 순서 우선) + 중국어·이탈리아어 셀 설명 문장부호. `breakCard.test.ts` 언어 목록과 zh/it 태그.
- 확인: typecheck:all 통과, a11y + breakCard + notify vitest 44/44.

## 2. 문자열 (it · zh-Hans · zh-Hant) + 원어민 관점 2차 검토 — 완료 (10:05)
- `a11y/strings.ts`: 기본(VoiceOver) 47개 + P5(설정·확인 카드) 30개 + V11(보이는 문장: 오류 줄, 힌트, 튜토리얼, "?" 시트, HUD 캡션, 완성, 결과 시트, 첫 데일리 카드) 75개를 세 언어로 새로 썼다. 언어 묶음 조립은 `BASE[l]` + P5 + V11 루프 하나로 정리(새 언어를 넣을 때 빠뜨릴 곳이 없다; `Record<Lang, …>`라 타입이 빠진 언어를 잡는다).
- `ads/breakCard.ts`(광고 휴식 확인 카드), `notify/texts.ts`(알림 4줄 + 연속 줄) 세 언어 추가. 알림 금지어(`BANNED`)에 it(perdi, perso, ultima, sbrigati, affrettati, mezzanotte)와 zh(错过/錯過, 最后/最後, 赶快/趕快, 赶紧/趕緊, 午夜, 半夜) 추가.
- 2차 검토: 언어별 원어민 역할 서브 에이전트 4개(it, zh-Hans, zh-Hant(대만), es 중립성)가 모든 문자열을 읽고 고칠 점을 냈고, 그중 분명히 나은 것을 반영했다.
  - it(약 30곳): "ne mancano 1" 문법 오류 → "ancora {k}", 등불끼리 "si vedono" → "si illuminano a vicenda", 성별 표현 피함("Tutto pronto!", "Ottimo!", "Vicolo cieco"), "disattivo"로 대칭, 캡션 "Tempo condiviso"(함께 보낸 시간으로 읽힘) → "Condividi il tempo", 광고는 "video"가 아니라 "annuncio", 대각선은 "diagonali", "riga"로 통일.
  - zh-Hans(약 25곳), zh-Hant(약 30곳): 斜角(빗각) → 斜对角/斜對角, 알림은 已… 형태(명령으로 들리지 않게), "×" 대신 行/列(zh-Hant 列/欄), 광고는 视频/影片이 아니라 广告/廣告(+ zh-Hant 看完), 放下 → 放一盏/放一盞, 캡션 规则/規則 → 玩法(시트 제목과 같게), 남은 보호막 "还剩/剩", 擋住(물리적으로 막음) → 让这题解不开.

- 기존 언어의 용어 통일(용어집과 맞춤, VoiceOver ↔ 화면 글자): en "rock" → "stone", ja 岩 → 石·取り消す → 元に戻す(캡션과 같게), fr "Puzzle"·"rocher" → "Énigme"·"pierre". ko는 이미 일관돼 그대로.

## 6. 남은 일 / 확신이 덜한 문자열
- 번역은 AI 작성 + AI 원어민 역할 검토다. 출시 전 실제 원어민(it, 대만, 싱가포르/말레이시아) 한 번씩 읽어 보기 권장.
- zh-Hant VoiceOver의 행·열(第 n 列，第 n 欄)은 대만식이다. 홍콩은 行/列을 반대로 쓰므로 홍콩 사용자에게는 헷갈릴 수 있다(대안: 橫列/直欄).
- zh-Hans "回家"(집으로 버튼), zh 데일리 소개 "连续记录就能接着算"/"連續紀錄繼續累積", it "Indizio"(힌트; "Suggerimento"는 캡션 폭 초과), it "borgo"(마을), es "acertijo"(검토자는 유지 권장)는 취향이 갈릴 수 있다.
- 기존 언어에서 그대로 둔 것: fr 설정 캡션 "Politique de confidentialité"가 EEA에서 ×0.88로 줄어 보임, pt-BR "Tempo ao compartilhar"가 폭과 같음.
- 실기기에서 PingFang TC/SC 지정이 WKWebView 캔버스에 적용되는지(코드상 문제 없음, Chromium·WebKit 데스크톱에서 확인) 한 번 눈으로 확인하면 좋다.
