# Duskwick 번역 QA 보고서 (원어민 검토 없이 출시할 때) — 2026-10-18

범위: en을 뺀 9개 언어(ko, ja, de, fr, es, pt-BR, it, zh-Hans, zh-Hant). 원어민 검토가 불가능해서 **"영어 원문을 보지 않는 역번역 + 원문 대조 + 규칙 검사"**로 대신했다.
진행 기록: `playtest/i18n-qa.md`. 용어·말투 결정은 `docs/i18n-glossary.md` 끝의 "QA 2026-10-18"에 반영했다.

> 이 문서는 원어민 수준의 품질을 주장하지 않는다. 아래는 "AI 번역이 낼 법한 오류 중 기계적으로 잡히는 것을 잡았다"는 뜻이다.

## 1. 방법

1. **추출**: 로캘마다 498개 문자열(UI·VoiceOver·튜토리얼·오류·"?" 시트·광고 확인 카드·알림 5줄·ATT 문구·마을 UI/아이템/탭/주민 이름·마을 대사 195줄·말버릇 7개·스토어 캡션·스토어 이름/부제/키워드)을 키와 함께 뽑았다. 합계 9개 언어 × 498 = **4,482개**(+ en 원문 498).
2. **블라인드 역번역**: 언어마다 서브 에이전트 1개를 새로 띄웠다. 입력은 그 언어 문자열(번호만 붙임, 키 이름은 가림)뿐이고, 영어 원문·저장소는 보지 못하게 했다. 각 문자열을 영어로 되옮기고, 어색함·모호함·말투 혼용·문법(성/수 일치, 관사)·표기 규칙·용어 불일치·오해 소지를 표시하게 했다. 표시 건수: ja 28 · fr 35 · pt-BR 27 · ko 24 · es 19 · it 18 · de 16 · zh-Hans 15 · zh-Hant 11.
3. **대조**: 역번역을 영어 원문·용어집과 비교해 의미 이탈, 용어 불일치, 말투를 직접 판단했다. 대사 195줄 × 8개 언어는 전부 직접 읽었다.
4. **기계 검사**: 자리표시자 일치, 프랑스어 `? ! : ;` 앞 공백, 일본어·중국어 반각 문장부호, 한자와 라틴/숫자 사이 공백, 간체/번체 혼입, "당신/您", 영어가 남은 문자열, 줄 길이.
5. **수정 후 검증**: 고친 소스를 다시 추출해 의도한 값과 한 글자도 다르지 않은지 대조(부수 변경 0건. 한 번 es 두 곳과 zh-Hant 한 곳이 같은 문자열 때문에 같이 바뀐 것을 이 대조로 잡아 되돌렸다).

### 전 언어 공통으로 나온 것
- **광고 쉬기 라벨이 "동영상"이라고 말했다**(en 포함 7개 언어). 광고 카드는 "광고"라고 말하는데 VoiceOver 라벨만 달랐다. AdMob 공개 요건(광고임을 분명히) 관점에서 가장 먼저 고쳤다.
- **수량과 숫자의 일치**: "1 días", "Quedan 1", "faltam 1" 같은 단·복수 문제가 es·pt·it·fr·de에 있었다. 숫자를 문장 끝으로 보내는 구조("…días iluminados: {done}")로 바꿔 규칙 없이 피했다.
- **모서리(corners)**: fr "coins", pt "cantos", de "Ecken"은 "보드의 모서리"로 읽힌다. fr·pt는 "diagonales/diagonais"로 바꿨다(de는 "Ecken"이 대각선 이웃으로 통해 그대로, 아래 불확실 목록).

### 언어별 중요한 수정 (몇 개)
- **fr**: UI 문자열 30여 곳이 일반 공백이라 `?` `!` `:`가 줄 맨 앞으로 갈 수 있었다(마을 대사 JSON은 이미 NBSP) → ` `. 스토어 캡션 "Un petit ami dans chaque lanterne"는 프랑스어로 "남자친구/여자친구"다 → "petit compagnon". 마을 UI에 tu/vous가 섞여 있었다("Ta cabane", "Choisis-en un") → UI는 vous, 주민 대사만 tu.
- **pt-BR**: 튜토리얼 오류 "Demais!"는 브라질에서 "대박!"으로 들려 틀린 수를 칭찬하는 것처럼 읽힌다 → "Lanternas demais!".
- **es**: "Dos faroles se iluminan"은 "두 등불이 켜진다"(오류 문구인데 좋은 소식처럼 읽힘) → "…entre sí". "Bola de nieve"는 눈덩이 → "Globo de nieve". 스페인 전용 "Portarretrato", 중남미 전용 "Canasta"를 중립어로.
- **de**: "Morgen"만 쓴 인사가 "내일"로 읽힌다 → "Guten Morgen". 없는 단어 "einen Wärmer" → "Strickmütze". "Punkte statt Zahlen"(점수) → "Zahlen als Punkte".
- **ja**: 村/町 혼용 통일, `?`/`:` 반각 → 전각, "やり直す"(redo로 읽혀 "되돌리기"와 반대) → "最初から", ATT 문구의 번역투와 라틴 글자 주변 공백. 스토어 이름의 "脳トレ"(상표 가능성·차분한 톤과 안 맞음)를 뺐다.
- **it**: 여성 명사 아이템 뒤에서 틀리는 남성형("è già tuo", "Mettilo", "spostalo")과 편지의 "è caduto / Trovato"를 성 중립으로.
- **zh**: Wick이 화면에 따라 "Wick"/"小烛"으로 달랐다 → 小烛/小燭. "没用提示"는 "쓸모없는 힌트"로 읽힌다 → "未使用提示". 간체 ATT "不允许也不会影响"가 두 번 부정으로 오해될 수 있어 "即使你选择不允许，…"로. 번체 "小夥伴"(대륙식), "佈置" 정리.
- **ko**: "이제 당신 차례!"(용어집이 금지한 "당신")가 공유 카드에 하나 남아 있었다 → "이제 해 볼 차례!". "이 {n}"은 소리 내어 읽으면 "이 이"라 "{n} 숫자"로.

### 고치지 않고 둔 것 (알고 둠)
- 블라인드 에이전트가 "1시간 광고 없음(ui.gift)과 30분이 다르다"고 전 언어에서 표시했으나, 이는 7일 연속 보상(1시간)과 광고 쉬기(30분)가 다른 기능이라 맞는 문구다.
- ko ATT는 합쇼체 그대로(Apple 한국어 권한 문구 관례, 보수적).
- pt-BR 대사의 tu형 명령(Senta, Olha, Toma)은 브라질 구어에서 흔해 그대로.
- 스토어 키워드의 "sans", "ohne,internet" 분리는 App Store가 키워드를 조합하는 방식이라 의도(ASO 담당 결정).
- 설정 캡션 fr "Politique de confidentialité", pt-BR "Tempo ao compartilhar"의 폭 초과는 기존 알려진 것(fit-report).

## 3. 남은 불확실성 (위험 순)

위험 = (틀렸을 때 사용자·심사·평점에 미치는 영향) × (틀렸을 가능성).

1. **ATT 설명문(9개 언어)과 광고 확인 카드·알림 문구** — 영향이 가장 크다(심사, 개인정보, 광고 공개). 수정 후 문장은 짧고 보수적이지만, 법적 뉘앙스("식별자", "허용하지 않으면")의 자연스러움은 원어민이 봐야 확정된다. 심사에서 거절될 가능성은 낮아 보이나 0은 아니다.
2. **스토어 이름·부제·키워드** — 검색 노출에 직접 영향. ja 키워드 "無料"·"大人", ko "무료", zh "免费/免費"는 가격 표현 정책과 아슬아슬하다(이름·부제에는 없음). es-MX 부제는 의도적으로 "Rompecabezas"(검색어) 유지, 스페인 es-ES는 "Puzle".
3. **zh-Hant 행/열**: 대만식(列=행, 欄=열). 홍콩 사용자는 반대로 읽는다. 홍콩이 주 시장이면 "橫列/直欄"로 바꿔야 한다.
4. **주민 말버릇 의성어**(fr Pof·Cling, it Dlin·Pof, es Tilín, de Plopp 등)와 이름 연상(Wick = 독일 감기약 브랜드, Momo = 2019 괴담, ja ピピ vs ピップ): 서술자 문서에서도 "확신 낮음"이라 적었다. 해가 되지는 않지만 어색할 수 있다.
5. **fr "cabane"**(오두막=헛간 느낌, 대신 "petite maison/chaumière" 논의 가능), **"pas japonais"**(징검돌 — 정원 용어), **de "Hütte"**, **it "borgo"/"casetta"**: 취향·톤 문제. 틀리진 않았다.
6. **ja 히라가나 위주의 부드러운 표기**(ちゃぶ台, かべ, 本だな)는 아이 느낌이 난다. 35–54세 대상이면 한자 비율을 높이는 편이 나을 수 있다(저위험).
7. **성별·수 일치**: 항목 이름을 문장에 끼우는 곳({item})에서 es/pt/it/fr는 성 일치를 구조적으로 피했지만, 아이템 이름이 늘어나면 다시 검사가 필요하다.
8. **중립 어휘의 지역차**: es(스페인·중남미), pt-BR(브라질 외 포르투갈은 배포 시 pt-BR 하나), zh-Hans(싱가포르·말레이시아 vs 본토).
9. **AI 공통 맹점**: 역번역 에이전트도 같은 계열의 AI라서 "AI가 자연스럽다고 느끼지만 원어민은 어색해하는" 표현은 구조적으로 못 잡는다. 그래서 아래 신뢰도에서 언어별 상한을 둔다.

## 4. 원어민 검토 없이 출시할 때의 신뢰도 (정직한 추정)

두 숫자를 나눠 적는다. A = 심각한 오류(오해·불쾌·잘못된 안내·정책 위반 소지)가 출시본에 남아 있지 않을 가능성. B = 원어민이 "자연스럽다"고 느낄 가능성(아주 어색한 문장이 거의 없음).
이 수치는 검증 데이터가 아니라 내 판단이다.

| 언어 | A 심각 오류 없음 | B 자연스러움 | 근거 |
|---|---|---|---|
| ko | 높음(~90%) | 높음(~80%) | 소유자가 한국어 원어민이라 직접 읽을 수 있다. 번역이 아니라 원문 언어다. |
| ja | ~80% | ~60% | 존댓말·대사는 안정적. 표기(한자/가나)와 말버릇 톤 취향이 갈린다. |
| de | ~85% | ~70% | 구조가 영어와 가깝고 du로 일관. |
| fr | ~80% | ~65% | 공백·존칭 수정 후 안정. "cabane"·의성어가 미확인. |
| es | ~80% | ~65% | 중립어 의도. 지역차로 약간 어색할 수 있음. |
| pt-BR | ~80% | ~65% | 수정 후 안정. 구어/문어 혼합 정도가 남음. |
| it | ~80% | ~65% | 성 중립 처리로 위험은 낮음. |
| zh-Hans | ~75% | ~60% | 대상 시장이 싱가포르·말레이시아. 어휘가 본토에 치우쳤을 수 있음. |
| zh-Hant | ~75% | ~60% | 대만 어휘로 맞췄으나 홍콩·마카오는 미확인. |

종합: **심각한 오류가 남았을 위험은 낮지만(언어별 10–25%), "원어민이 읽어도 매끄럽다"를 보장하지는 못한다.** 출시는 가능하되 아래 관찰 루프를 같이 켜는 것을 권한다. 평점·리뷰에 번역 불만이 나오면 그 언어를 우선 외주 교정(수십 달러 수준의 프리랜서 1회 검수)으로 올린다. 비용 0원 원칙이라면 리뷰 지표가 기준이다.

## 5. 출시 후 저비용 점검 루프

1. **앱 안 신고 경로(권장, 코드 몇 줄)**: 설정에 "문구 제안" 한 줄 → 지원 페이지(`/support`)의 로캘별 앵커로 연다. 페이지에 짧은 폼 하나(Google Form 또는 GitHub 이슈 템플릿: 언어, 화면, 어색한 문구, 제안). URL 상수는 다른 엔지니어가 바꾸는 중이라 이번엔 건드리지 않았다. 대안은 지원 이메일로 가는 `mailto:` 한 줄.
2. **스토어 리뷰 모니터링(주 1회, 15분)**: App Store Connect → 평점 및 리뷰에서 국가별(JP, DE, FR, ES/MX, BR, IT, TW/HK, SG) 필터로 읽는다. 키워드: 번역, 어색, translation, Übersetzung, traduction, 翻訳, 翻譯, 번역. 번역 불만이 2건 이상 나온 언어부터 손본다.
3. **빠른 패치**: 문자열은 코드 안 데이터라 `strings.ts`·`lines/*.json` 수정 → 1.0.x 패치로 낸다. 심사 24–48시간. 신고가 쌓이면 월 1회 모아 낸다(용어집 `docs/i18n-glossary.md`와 `scripts/village-lines.mjs --check`, 글꼴 서브셋 재생성, fit/G3 검사는 이 문서의 명령을 그대로 쓴다).
4. **TestFlight 외부 테스터 소수**: 각 언어 지인·커뮤니티(해당 언어 사용자 3–5명)에게 TestFlight 링크 한 번. 튜토리얼과 광고 카드, ATT만 읽어 달라고 하면 10분이면 된다. 사례 비용 0.
5. **회귀 방지**: 이번에 쓴 검사(자리표시자·NBSP·간번체 혼입·"당신"·반각/전각)를 `tests/`에 상시 테스트로 옮기면 다음 문구 추가 때 같은 실수를 자동으로 막는다(이번엔 임시 스크립트로만 돌림, 추가 시간 약 1시간).
6. **순서**: ① 광고 카드·ATT·알림은 먼저 TestFlight 테스터 1명씩 ② 불만이 나온 언어만 외주 검수 ③ 1.1에서 홍콩 시장이 중요하면 zh-Hant 행/열 재검토.
