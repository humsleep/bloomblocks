# R1 비주얼·캐릭터 — Wick v2 (2026-10-17, UI Designer)

> 오너 요청: "Wick을 보여 달라. 여성이 좋아하도록 귀여워야 한다."
> 타깃: Tier-1 국가(US, UK, DE, FR, JP, KR 등)의 35–54세 여성. 목표: App Store 퍼즐 1위.
> 이 문서의 페르소나 점수는 **AI가 시뮬레이션한 값이며 실제 사람 데이터가 아니다.** 실제 검증 방법은 §7에 적었다.

## 0. 결론 (한 줄 + 근거 3개)

**B+ "모찌 Wick"을 채택한다.** 몸은 뾰족한 끝이 없는 납작한 모찌형이고, 눈은 몸 아래쪽(60% 지점)에 작게 넓게 놓는다. 불꽃은 몸에서 떨어진 채 오른쪽으로 비켜 떠 있다.
1. **시뮬레이션 페르소나 평균**(8명): 귀여움 8.3, 홈 화면에 두고 싶음 8.0, 유치함 위험 3.4. 현재 v1은 6.0 / 4.9 / 4.3이다. 상세는 §3.
2. **오독 테스트**: 실루엣 IoU 최대값이 v1 0.79(양파), B 0.84(양파)에서 **B+ 0.76**으로 내려갔다. 네 후보 중 가장 덜 헷갈린다. 상세는 §4.
3. **구현**: Path2D 문자열 12개와 ellipse/arc만 쓴다. 비트맵은 0 KB다. 친구 6명도 같은 몸과 같은 얼굴 리그를 쓰고 팔레트·불꽃 모양·소품 1개만 바꾼다.

| D | **0.88** | 0.74 | 0.68 | 0.72 | 0.88 |
| **B+** | 0.76 | 0.75 | 0.66 | 0.69 | **0.76** |

**수정 과정**
- 불꽃의 x 오프셋 {2.5, 5}, 띄움 {0, 3}, 기울기 {10°, 20°}, 크기 {0.7, 0.85}의 16개 조합을 탐색했다.
- 최대 IoU가 가장 낮은 조합은 오프셋 5, 띄움 3, 기울기 10°, 크기 0.85(0.764)였다. 정중앙 0.7배 조합은 0.89까지 올라갔다.
- 비교 기준선: 그냥 타원(커비·몰랑형)은 만두와 0.90이다.
- 결론: **둥근 마스코트는 실루엣만으로 찐빵과 구분되지 않는다.** 구분은 아래 단서들이 맡는다.

## 6. 비용과 위험 (반론 선제 대응)

**비용**
- `src/render/wick.ts` 약 250줄(경로 + 얼굴 + 모션 함수 4개)과 보드 렌더러의 등불 얼굴 레이어 1개.
- 첫 프레임 경로에서는 빼고 지연 생성한다(Path2D 캐시). 콜드 스타트 게이트(p75 ≤ 1.0 s)에는 영향이 없을 것으로 예상하지만, 구현 후 측정해야 한다.

**위험**
- ① **퍼즐 코어 팬(Queens·LinkedIn 계열)의 이탈**: 등불 얼굴 끄기 토글과 차분한 모션으로 대응한다.
- ② **보드 가독성**: 얼굴은 유리 안에만 그리고, 잉크 대비는 4.5:1 이상이다. 충돌 표시(코랄 ✕와 링)는 그대로 둔다. 얼굴은 보조 신호일 뿐 유일한 신호가 아니다.
- ③ **페르소나 점수의 자기 편향**: §7의 실제 테스트 전까지 결정은 "잠정"이다.
- ④ **만두 오독**은 실루엣으로 완전히 없앨 수 없다(§4). 글로우·불꽃 규칙을 지켜야 한다.
