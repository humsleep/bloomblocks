## 0. 결론

1. **"대형 스튜디오처럼 보이는" 것의 정체는 기술보다 규칙의 일관성이다.**
   - 광원 하나, 셰이딩 레시피 하나, 외곽선 규칙 하나, UI 문법 하나.
   - 모든 물건이 같은 빛을 받고 같은 그림자를 바닥에 떨어뜨리면, 절차적으로 그린 그림도 한 장의 일러스트로 읽힌다.
   - 키트는 이 규칙을 코드로 강제한다. 모든 고형물은 `solid()` 함수 하나로만 칠한다.
2. **마을의 정체성은 "등불 집"이다.**
   - 집 자체가 커다란 종이 등불이다: 부푼 종이 몸통, 주민 색의 나무 뚜껑 지붕, 손잡이, 동그란 문.
   - "Wick이 등불 속에 산다"는 브랜드가 마을 크기로 커진다. 동물의 숲 복제가 아닌 Duskwick만의 실루엣이다.
3. **방은 정면 단면 "인형의 집"이다.**
   - 칸 18개에 딸깍 맞물리고, 앞줄로 갈수록 살짝 커지는 원근만 준다. 아이소메트릭은 쓰지 않는다.
   - 이유: 절차적 그림 비용(물건당 각도 1개), VoiceOver(칸 = 버튼), 실수 방지(자유 드래그 없음).
4. **시범 가구 6종은 출시 품질에 가깝다(판단).**
   - 물건 하나가 그리기 함수 49–80줄이다.
   - 색 변형은 토큰 3개(base·hi·lo)라 추가 비용이 없다.
   - 나머지 18종의 비용은 §4.
5. **남은 차이(정직하게)**: 마을 땅이 아직 차갑고 비어 보인다. 목업 (d)에는 합성 흔적이 있다(§3).

## 2. 마을 콘셉트

### 2.1 광원 모델과 토큰 (`kit.js` 상단 `T`)

**색 토큰**
- 하늘: #191838 → #352C5E → #77598C → #D18E9D → #F4BFA0. 잔광은 왼쪽 지평선에서 온다(= 주광 방향).
- 땅: 황혼 잔디 #3F4B78 → #2C3260, 밝은 반점과 꽃 무더기.
- 나무: #7A5440 / #A57B5C / #4A3328.
- 잎: #4F7F68 / #86C29C.
- 종이: #FFF3DE. 잉크: #3B2C45.
- 강조: 앰버 #FFC864 / 립 #D9983F. 친구 색: pink·mint·lilac·lemon·coral.

**셰이딩 레시피 `solid()`** — 모든 고형물이 같은 순서로 칠해진다.
1. 바탕색
2. 주광 그라데이션: 왼쪽 위 key 26% → 오른쪽 아래 plum 34%
3. 아래쪽 AO 22%
4. 안쪽 림라이트: 경로를 (+r, +r) 옮겨 그어 왼쪽 위 가장자리만 밝게
5. 안쪽 그늘: (−r, −r)로 옮겨 오른쪽 아래만 어둡게
6. 외곽선: 바탕보다 한 단계 어두운 자두색, 0.5–1.2 pt

**보조 함수**
- `contact()`: 접지 타원 그림자
- `glow()`: 등불·창 빛, 가산 합성
- `grain()`: 화면 전체 5–7% 오버레이 노이즈(회화풍 질감)
- `vignette()`

### 2.2 등불 집 (`lanternHouse`)

**형태**
- 몸통: 부푼 종이 통 + 갈비살 3줄 + 휘어진 대나무 살 2개
- 지붕: 주민 색 나무 뚜껑 + 비늘 기와 + 처마 립 + 손잡이 고리
- 문: 동그란 나무 문 + 문 옆 작은 등불
- 창: 동그란 창 1–2개(주민 색 커튼, 화분 상자)
- 빛: 종이 통 안쪽이 빛나고(방사형), 집 앞 땅에 따뜻한 웅덩이를 떨어뜨린다

**주민 테마** = 토큰 5개(paper, paperLo, roof, door, flower)
- 만든 것: Wick 호박색, Momo 장미, Sage 세이지, Luna 라일락.
- Pip·Kuri·Yuki도 같은 방식으로 만든다.

**소품**: 우편함(깃발 = 편지 있음), 울타리, 가로등, 화분 3종, 벤치, 연못(연잎·달 반사), 장터 노점(줄무늬 차양 + 하나 고르기 물건 3개 + 종), 줄등, 소풍 담요, 나무, 덤불, 꽃 무더기.

### 2.3 방: 정면 단면 인형의 집

**구성**: 등불 집 뚜껑 지붕 아래로 잘린 방 하나.
- 뒷벽(벽지 + 판벽), 양옆 벽(소실점 하나, 얕은 원근), 바닥판
- 천장 보에 줄등
- 동그란 창: 실시간 시간대·계절 하늘과 이웃 집이 보인다

**칸 18개**
- 바닥 3줄 × 5 = 15칸. 원근상 앞줄로 갈수록 1.5 → 1.7배 커진다.
- 벽 3칸.
- 러그 1층(바닥 아래).
- 큰 가구(침대)는 2칸을 차지한다.
- 빈 칸은 점선 타원, 선택한 칸은 앰버 고리와 "+".

**빛**: 주 광원은 종이 등불(왼쪽 위 따뜻한 웅덩이), 창은 차가운 보조광.

### 2.5 대사 카드·편지·선물·카탈로그

**대사 카드** (마을에서만)
- 화면 아래 종이 패널, 바늘땀 점선 테두리.
- 왼쪽에 주민 초상(원형 액자, 주민 색 테두리, 이름표).
- 1–2줄. 탭하면 다음 줄(▼ 표시).

**편지**
- 줄 친 종이, 손글씨체, 주민 서명 얼굴, 꽃잎 밀랍 봉인.
- 장미색 봉투가 뒤에서 열려 있다.

**선물**
- 열린 상자에서 빛이 나오고 물건이 떠오른다. 뚜껑은 비스듬히 날아간다.
- 이름 칩 + "new", 빛살 14개, 반짝이 5개. 주민 두 명이 양옆에서 반응한다.
- 버튼: "Put it in my cottage"(주 알약), "Later"(보조).

**카탈로그 서랍**
- 아래에서 올라오는 크림 패널 + 손잡이. 제목 "앞줄 · 3번 칸", 닫기 원판.
- 계열 칩(선택 = 앰버).
- 4열 카드: 물건, 이름, 색 점(선택 색은 잉크 테두리), 보유 수 ×n, NEW 리본.
- 잠긴 칸: 회색 실루엣 + 자물쇠 + 얻는 곳("from Sage", "at the market").

**앨범** (1.1): 같은 카드 문법. 주민 탭은 대사 카드 초상을 재사용한다.

### 4.2 굽기·메모리·콜드 스타트

**콜드 스타트 영향 0**
- 마을 전체를 동적 `import()` 청크로 둔다. 퍼즐 부팅 경로는 import하지 않는다(현재 town이 이미 이 방식).
- 마을 버튼을 처음 누를 때 청크를 받고, 층을 굽는 동안 기존 이동 연출(카메라 페이드)이 시간을 번다.
- 측정: Wick 때와 같은 Chromium 4× 교차 측정, +5 ms 이내.

**굽기 순서** (마을 진입 1회)
1. 하늘 + 먼 언덕(1층)
2. 중간 언덕 + 나무(2층)
3. 집·소품(3층, 집마다 이미지 1장)
4. 주민(Wick 텍스처 재사용)
5. 대기 동작 이미지(반딧불, 줄등 전구, 연못 반짝임)

예상 굽기 시간은 약 120–200 ms(iPhone 14 Pro, 판단, 측정 필요)다. 첫 프레임을 막지 않게 층 단위로 프레임을 나눠 굽는다.

**메모리 예산** (@3x, RGBA): 합계 상한 **약 40 MB**
- 하늘 1290×900 ≈ 4.6 MB
- 언덕 2층 ≈ 6 MB
- 집 7채 × 360×450 ≈ 4.5 MB
- 방 배경 1290×1230 ≈ 6.3 MB
- 가구 아틀라스 ≈ 15 MB(1.0: 24종 × 색 2 × 칸 크기 3단(카탈로그·뒷줄·앞줄) × 평균 150×180 px)
- 마을을 나가면 1–3층을 해제하고 아틀라스만 남긴다.

**대기 동작**: 모두 `ambient()` 20 fps. `keepAwake`는 말하는 주민 1명과 선물 연출에만 쓴다(퍼즐 화면과 같은 거버너 규칙).

### 4.4 위험
- **손글씨 글꼴**
  - macOS Noteworthy는 앱에 넣을 수 없다.
  - OFL 손글씨체 1종(라틴, 약 30 KB)을 마을 청크에서만 부른다.
  - CJK 편지는 Fredoka + 시스템 글꼴을 쓴다(손글씨 느낌은 떨어진다).
- **"동물의 숲 같다"와 표절 위험**
  - 주민·가구·편지는 장르 관습이다.
  - 실루엣·색·이름은 등불 집과 Wick 계열로 고유하게 유지한다.
  - 특정 IP의 디자인 요소는 쓰지 않는다.
- **땅이 차가워 보이는 문제(a)**: 시간대 틴트에서 더 두드러질 수 있다. 시간대별 땅 토큰을 따로 둔다.
- **판단의 근거**: 모두 AI 자기 평가다. 출시 뒤 PPO 스크린샷 A/B(마을·방 장면 vs 퍼즐 장면)로 확인한다.
